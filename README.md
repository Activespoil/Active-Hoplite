# Active Hoplite
A Fabric cosmetic mod for the Minecraft Hoplite Server

## 📌 About This Project
Active Hoplite is a custom cosmetic mod.
It includes custom cosmetics, skins and UI menus.
Cosmetics are visible to each other, **only valid for premium accounts**.

> ⚠️ Important Notice
> This mod is only for cosmetic display purposes.
> Please follow the rules of the Hoplite server. We take no responsibility for any account penalties caused by improper use.

- Game Version: Minecraft 1.21.11
- Loader: Fabric
- Fabric API is required

## 📥 Installation Guide
1. Install the Fabric loader for Minecraft 1.21.11
2. Put the Fabric API jar file into your mods folder
3. Place the Active Hoplite jar file into your mods folder
4. Launch the game with the Fabric profile
